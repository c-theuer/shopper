## What it is

Shopper is a web app where an AI agent does a person's routine shopping for them, within limits they set.
The user keeps a shopping list. During shopping hours the agent picks products from nearby stores, groups them
into one cart per store, and places orders. Anything outside the user's rules (too expensive, a substitute, over
budget) waits for their approval.

The core idea is **the AI proposes and plain code decides**: Claude helps interpret list items and choose
products, but every spending, distance, time, and category check runs in a deterministic guardrail engine
(`backend/app/guardrails.py`) that the AI can't override.

### Features in the demo

- **Shopping list** with clarifying questions from the agent ("What color lamp?").
- **Guardrails:** per-order and weekly limits, a 10-mile store radius, 10 a.m. to 5 p.m. shopping hours, rate
  limits, and blocked categories (medicines, bill payments, buy-now-pay-later).
- **Approvals** for purchases outside the user's rules, tied to the exact cart.
- **Payments:** a test card or a **wallet** funded from a linked test bank account.
- **Voice:** a "Talk to Shopper" panel uses Chrome's speech recognition to add or remove items, answer the
  agent's questions, and read the list aloud.
- **Inbox** showing the emails and texts the app would send, plus a daily summary.
- **Demo bar** to move the clock, run shopping, and reset to a sample user.

### What's fake

Everything that would touch the real world is mocked: the stores and products are seeded, nothing is bought,
no money moves, and no messages are sent. The card and bank forms accept only published test numbers.

## Running it

Requirements: Docker. Optionally set `ANTHROPIC_API_KEY` in `.env` to use Claude; without it the agent falls
back to simple keyword rules.

```bash
docker compose up --build
```

Open http://localhost:8080 in Google Chrome (needed for voice).

Tests (need the compose Postgres running):

```bash
cd backend && uv run pytest
```
